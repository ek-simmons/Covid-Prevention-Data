# Covid-19 and Prevention Behaviors 
Team MES: Sandra Salkini, Evelyn Simmons, Matthew Doyle
## How to run
1. Open project in CLion 
2. Select the 'Covid_Data' run configuration and click Run
3. Use the menu:
- 1: Search by country 
--> type name like 'united states' and it will show a table of cases next to prevention behaviors by month (names are not case-sensitive and spaces or underscores both work)
- 2: exit 
- 3: Compare the search times of the Trie and B-Tree 
--> searches all 214 countries 20 times in each structure (by full name and by prefix) and prints the total time for each
